# [记忆删除诊所](https://hoo.be/ytsp)

“第十一次治疗准备就绪，陆先生。”

诊所的白色房间里，陆泽宇深吸一口气，对着医生点了点头。他熟练地躺进那个像牙科诊所一样的座椅，闭上眼睛，等待电极贴片贴上他的太阳穴。

“今天要删除的是哪部分记忆？”医生例行公事地问。

“去年7月14日，我和她在海边看日出的场景。”陆泽宇平静地回答，声音里没有任何波澜。

“确认一下，记忆删除后，相关细节将从您的大脑中永久清除，不可恢复。您确定要继续吗？”

“确定。”

这是陆泽宇第十一次来到“记忆删除诊所”。自从三个月前与夏沫分手，他就开始定期来这里，有计划地删除与她的所有记忆。

治疗开始了，机器发出轻微的嗡嗡声。陆泽宇感到一阵头晕，脑海中浮现出那个海边的清晨：夏沫穿着白色连衣裙，赤脚在沙滩上奔跑，回头对他微笑；海风掀起她的长发，初升的阳光为她勾勒出金色的轮廓...

然后，像电视信号突然中断，画面消失了。取而代之的是一种奇怪的空白感。

“治疗结束。”医生说，“按照惯例，这是您记录删除原因的笔记。”

陆泽宇接过那张卡片，上面写着：“删除与夏沫在海边看日出的记忆。原因：过度美好，与现实形成残酷对比。”

他点点头，把卡片收进口袋，离开了诊所。外面的世界一如既往地喧嚣，行人匆匆，没有人知道他又一次主动放弃了一部分自己。

回到家，陆泽宇打开电脑，查看自己的“记忆删除计划表”。这份表格详细记录了他与夏沫的七十三个重要时刻，按痛苦程度从低到高排列。他正在系统地删除所有这些记忆，从最不痛到最痛，像是拆解一枚精心组装的炸弹。

“真是讽刺，”他想，“我们曾经那么努力地创造记忆，现在我却更努力地删除它们。”

下一次去诊所时，陆泽宇删除的是他们一起在雨中等公交的记忆。再下一次，是他们在深夜电话里聊到天亮的记忆。每次删除后，他都会感到一阵轻松，仿佛卸下了什么重担。

但奇怪的是，随着删除的记忆越来越多，他开始在梦中见到夏沫。梦中的她没有面孔，只是一个模糊的轮廓，但他知道那是她。醒来后，他总是感到一种难以名状的失落。

“这是正常现象，”医生解释说，“大脑试图补偿那些空白区域。”

删除到第三十五个记忆时，陆泽宇开始注意到变化。他的世界似乎变得单调了，色彩不再那么鲜艳，食物不再那么美味，音乐也不再触动心弦。他删除的不仅是夏沫，还有与之相关的情感体验。

一天下午，陆泽宇在咖啡店偶遇了一位老朋友。

“嘿，陆泽宇！好久不见！夏沫怎么样？你们俩还在一起吗？”

陆泽宇愣住了，随即礼貌地笑笑：“我们分手了。”

“真遗憾！你们曾经那么相爱，所有人都羡慕你们。”

回家后，陆泽宇翻箱倒柜地寻找与夏沫有关的物品，却什么也没找到——他早在分手后就全部处理掉了。唯一剩下的是那本记忆删除计划表，和一堆记录删除原因的卡片。

他一张张翻看那些卡片：

“删除与她一起做饭的记忆。原因：她切菜时哼的歌总是萦绕耳边。”

“删除第一次吵架后和好的记忆。原因：拥抱的温度太过真实。”

“删除她生病时照顾她的记忆。原因：记得她依赖我的样子。”

看着看着，陆泽宇突然意识到一件事：他正在删除的，不仅仅是痛苦的记忆，更是自己生命中最为鲜活的部分。

第二天，陆泽宇没有按计划去诊所。他开车去了城郊的一个小湖——根据笔记提示，这里曾是他向夏沫求婚的地方。尽管相关的记忆已被删除，他仍然希望这个地方能唤起什么。

湖面平静如镜，四周一个人也没有。陆泽宇站在湖边，努力回想，脑海中却只有一片空白。这时，一位钓鱼的老人走了过来。

“年轻人，你看起来迷路了。”

“不，我只是...试图记起一些事情。”陆泽宇说，“您经常来这里吗？也许见过我？大概一年前，我可能在这里向一个女孩求过婚。”

老人眯起眼睛：“哦！我记得你们！那天傍晚，你准备了整整一湖面的纸船，每只船上都有小蜡烛！夕阳西下时，整个湖面都在发光。那女孩哭得说不出话来。”

陆泽宇听着老人的描述，心中涌起一阵酸楚。如此美丽的记忆，他却主动选择了遗忘。

“为什么我要删除这样的记忆？”他喃喃自语。

回到家，陆泽宇重新审视自己的记忆删除计划。在表格的最后，他用红笔标注着最终要删除的内容：“第一次见面，她的笑脸。”

他突然明白了什么，疯狂地翻找那些记录删除原因的卡片，把它们按时间顺序排列。随着阅读，一个模式逐渐清晰：他删除记忆的真正原因，不是因为那些记忆太痛苦，而是因为它们太美好；不是因为想忘记夏沫，而是因为太爱她，无法承受失去她的痛苦。

第二天，陆泽宇再次来到记忆删除诊所，但这次目的不同。

“医生，有没有办法恢复已删除的记忆？”

医生遗憾地摇头：“技术上不可能。记忆一旦删除，就永久消失了。”

“那我还剩多少关于她的记忆？”

医生调出记录：“按照您的计划，已经删除了五十三个记忆单元，还剩下二十个，包括最初见面的记忆。”

陆泽宇沉默良久，然后说：“我想终止计划。剩下的记忆，我要保留。”

“确定吗？根据记录，剩下的记忆中包括一些相当痛苦的内容。”

“确定。痛苦也好，快乐也罢，它们都是我的一部分。”

从诊所出来，陆泽宇感到一种奇特的解脱。他意识到，试图通过删除记忆来逃避痛苦是徒劳的，因为真正难以忍受的不是记得，而是忘记——忘记自己曾经那么深刻地爱过，忘记生命中最美好的部分。

当晚，陆泽宇梦见夏沫又一次。这次，她的脸清晰可见，微笑着对他说些什么。醒来时，他发现自己脸上有泪，但心中却比几个月来都要平静。

他走到书桌前，开始写下那些尚未删除的记忆片段，尽可能详细地记录每一个细节。同时，他也开始拜访老朋友，收集他们眼中的自己和夏沫。

渐渐地，一幅残缺但依然美丽的爱情图景重新浮现。陆泽宇明白，他永远无法找回那些已删除的记忆，但可以选择如何对待剩下的。

生命中的爱情或许会结束，但爱过的事实永远不会消失。即使记忆可以被科技抹去，爱在生命中刻下的痕迹却永远存在。

陆泽宇决定，从今往后，他要好好珍藏剩下的二十个记忆，让它们成为自己继续前行的力量，而不是背负的痛苦。

因为最终，我们不是由我们记得什么或忘记什么定义，而是由我们爱过什么，以及如何爱而定义。
